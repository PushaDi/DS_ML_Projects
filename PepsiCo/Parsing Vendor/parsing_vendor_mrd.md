## 12. Критерии отсева

Поставщик **не проходит квалификацию**, если:

1. Не покрывает ритейлеров Приоритета 1 (SAMOKAT, YANDEX_LAVKA, PYATEROCHKA)
2. Доступность данных < 99.5%
3. Отсутствует API для интеграции
4. Нет возможности предоставить данные до уровня точки и GTIN
5. Нет выделенного технического менеджера
6. Данные поставляются только через облако или почту
7. Нет данных с января 2026
