# LAVKA Incremental Loader

Инкрементальный Databricks-ноутбук для загрузки данных Лавки из SharePoint в `ECOM_ETL` с сохранением истории изменений метрик.

## Состав

- `LAVKA_INCREMENTAL_LOADER.ipynb` — основной ноутбук загрузки.
- `DESCRIPTION.md` — краткое описание назначения и потока данных.
- `DECISIONS.md` — ключевые архитектурные решения и почему они приняты.

## Что делает ноутбук

- Загружает файлы из нескольких SharePoint-директорий (PO1, archive, KUB, WBD).
- Загружает только новые файлы.
- Пишет данные в таблицы в режиме `append`.
- Сохраняет служебные поля `_source_file` и `_loaded_at` для трассировки версий.
- Учитывает 10-дневное weekly-перекрытие: новые файлы с обновленными метриками сохраняются как новая версия данных.
- После успешной загрузки очищает содержимое staging-папок в DBFS, сохраняя сами папки.
