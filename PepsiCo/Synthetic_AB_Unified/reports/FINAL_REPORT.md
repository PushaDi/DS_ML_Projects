# Финальный отчёт: оценка uplift маркетинговых инструментов в Самокате

**Дата**: 2026-05-11
**Задача**: при отсутствии возможности классического A/B теста оценить эффект 8 маркетинговых инструментов на продажи 242 SKU за 57 недель (455 кейсов активаций).

---

## TL;DR (главный ответ)

**Лучший подход — двухслойный консенсус: SCM (Augmented Synthetic Control) + HBM с лог-таргетом.** Эти два метода даже на «грязных» данных Самоката согласуются в 73 % кейсов по знаку и дают коррелированные оценки. GSC+IFE и Matrix Completion при текущем T=57 недель **систематически смещены** и должны использоваться только как sanity-check, а не как primary inference.

## 1. Что было сделано в существующем проекте

В `PepsiCo/Synthetic_AB/Test 2.1/` уже посчитаны 4 независимых метода:

| Метод | Описание | n cases | Лит. |
|---|---|---|---|
| **SCM** | Synthetic Control + 3 маршрута (A/B/C) + placebo | 455 → 321 хороших | Abadie 2010 |
| **GSC+IFE** | Generalized SC c interactive fixed effects | 241 | Xu 2017 |
| **MC** | Matrix Completion с nuclear-norm | 247 | Athey et al. 2021 |
| **HBM** | Иерархическая байесовская модель на log(sales), pooled по tool×category | 321 | Gelman et al. |

Эти методы запускались независимо, и для каждого считались `per_case_full_results_v2.csv`, `*_tool_summary*.csv` и попарные сравнения.

## 2. Ключевая находка мета-анализа: методы противоречат друг другу

Сводя все 4 метода в одну таблицу `unified_per_case.csv` (321 хороший кейс), получаем:

### Попарная согласованность методов

| Пара | Pearson corr | Sign agreement | Кейсов |
|---|---|---|---|
| **SCM ↔ HBM** | **+0.25** | **73 %** | 321 |
| SCM ↔ MC | +0.03 | 69 % | 231 |
| HBM ↔ MC | +0.06 | 68 % | 231 |
| **SCM ↔ GSC** | **+0.02** | **39 %** | 222 |
| HBM ↔ GSC | +0.06 | 36 % | 222 |
| GSC ↔ MC | +0.22 | 38 % | 202 |

**Интерпретация:**
- **SCM и HBM — единственная пара с осмысленной корреляцией и согласием по знаку**. Это и есть надёжное ядро.
- **GSC систематически даёт оценки противоположного знака** (sign agreement 36–39 %). Причина: при T=57 недель и rank=5 IFE «съедает» эффект активаций, относя его к латентным факторам. Это известная слабость GSC при малом T (Athey & Imbens 2021).
- **MC даёт сильно завышенные положительные оценки** (например, Брендированная подборка +65 %). Nuclear-norm regularization не штрафует extrapolation на test-period, и модель overfit'ится на pre-period.

`★ Insight ─────────────────────────────────────`
Когда 4 метода считаются независимо, инстинктивно хочется усреднить — но это ловушка. **Усреднение смещённых оценок не убирает смещение**. Правильный подход — диагностика согласованности через попарные корреляции, и оставлять только пары, которые validate друг друга через независимые предположения (SCM требует параллельных трендов в pre-period; HBM требует exchangeability внутри tool×category — это разные предположения, поэтому их согласие = доказательство).

## 3. Ресерч SOTA-методов (май 2026)

Для задачи «uplift без A/B» сейчас актуальны:

| Метод | Когда применять | Источник |
|---|---|---|
| **Augmented SCM (Ridge)** | Малое число доноров, плохой pre-fit. Снижает bias на 75 % vs vanilla SCM | [Ben-Michael, Feller, Rothstein 2021](https://www.nber.org/papers/w28885) |
| **Synthetic DID (Arkhangelsky)** | Когда parallel-trends под сомнением. Doubly robust, лучше SCM и DID | [Arkhangelsky et al. 2021, AER](https://www.aeaweb.org/articles?id=10.1257%2Faer.20190159) |
| **CausalImpact (BSTS)** | Когда нужна временная динамика uplift + uncertainty по неделям | [Brodersen et al., Google](https://research.google/pubs/inferring-causal-impact-using-bayesian-structural-time-series-models/) |
| **Bayesian SCM + horseshoe priors** | Когда доноров много и нужна sparse selection с uncertainty | [Pang et al. 2026](https://www.sciencedirect.com/science/article/abs/pii/S0264999326000313) |
| **Causal Forest + DML** | Гетерогенные эффекты по сегментам товаров | [Wager-Athey, Chernozhukov DML] |
| **Dynamic SCM vs Panel-aware DML** | Multi-period interventions, рекомендуется параллельный запуск | [KDD 2025 causal workshop](https://causal-machine-learning.github.io/kdd2025-workshop/papers/3.pdf) |

**Что из этого уже есть в проекте**: SCM (route B = ridge-augmented), HBM (≈ Bayesian SCM).
**Чего не хватает**: **Synthetic DID** и **CausalImpact (BSTS)** — оба идеально подходят для текущей задачи и закроют слабости имеющихся методов.

## 4. Финальная методология (рекомендация)

```
                ┌─────────────────────────────────────────┐
                │  Per-case estimate (placement × SKU)    │
                └─────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
    SCM (route A/B/C)    HBM log-target       Synthetic DID*
    + placebo p-value    posterior median     (NEW, добавить)
        │                     │                     │
        └─────────┬───────────┴─────────┬───────────┘
                  ▼                     ▼
            Consensus median         Confidence:
            (SCM + HBM)              HBM prob_positive
                                     × placebo p-value
                  │                     │
                  └──────────┬──────────┘
                             ▼
              Tool × Category rollup
              (median по case'ам инструмента)
                             │
                             ▼
              Бизнес-рекомендация
```

\* На текущих данных ещё не запущено — это next step (см. § 6).

### Почему именно SCM + HBM:
1. **Разные предположения** — независимые источники ошибки.
2. **SCM даёт точечную оценку с placebo confidence**, HBM даёт **полное posterior**.
3. **Согласованность 73 %** — высокая для таких различающихся подходов.
4. **HBM пулит информацию по tool×category** — стабилизирует оценки для редких инструментов (Полка «Лучшее», Вертикальный слайдер).

## 7. Итог одной строкой

> **Полка «Лучшее» (+27 %)** и **Приоритезация в поиске (+16 %)** — два инструмента, в эффективности которых мы уверены статистически (SCM ↔ HBM согласие, HBM prob_positive > 0.90). Остальные работают слабее или результат неустойчив. **Слайдер в корзине (−25 %)** стоит отключить. До получения 2+ лет данных или возможности A/B все индивидуальные оценки по SKU нужно интерпретировать только в агрегате на уровне инструмента×категории.
